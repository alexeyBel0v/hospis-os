# Hospis OS — версия 0.4

Приложение в Telegram для выездной работы с пациентами: кто сегодня, кто просрочен, раны, катетер, аллергии, справка для сотрудников.

## Запуск на компьютере

1. Установите **Node.js LTS** с https://nodejs.org.
2. Распакуйте архив, откройте папку `hospis-os` в VS Code (**File → Open Folder**).
3. **Terminal → New Terminal**:

```
npm install
npm run dev
```

4. Откройте `http://localhost:5173`. После заставки введите ключ доступа **hospis** и выберите должность.
5. Нажмите **«Посмотреть на примере»** — появятся 3 вымышленных пациента (ежедневно с катетером, 1/3 с концентратором, 1/7 с цистостомой). Убрать: **Настройки → Удалить все данные**.

С телефона в той же Wi-Fi сети — адрес из строки `Network:` в терминале. Остановить: `Ctrl + C`.

## Что умеет

- **Сегодня** — дата, «отмечено 2 / 5», карточка «Следующий» с маршрутом, полоса дней на неделю, группы «Просрочено / Сегодня / Завтра / Потом», кружок-галочка для отметки визита.
- **Пациенты** — список по алфавиту или по дате визита, поиск, фильтр «Катетер», архив. Метки: **К** — катетер, **O₂** — концентратор, **!** — аллергия.
- **Карточка** — адрес с маршрутом, несколько телефонов с подписью «чей», домофон; «Был сегодня» и «Перенести»; блок «О пациенте»: аллергия, схема тела с поворотом и отметкой пролежней по стадиям, катетер (тип и Ch 14–28), кислородный концентратор; комментарий и история.
- **Календарь** — месяц: сколько отмечено и сколько по графику.
- **Справка** — новости, приказы и инструкции для сотрудников.
- **Настройки** — график по умолчанию, что показывать под ФИО, тема, копия данных, обмен с коллегами.

## Ключ доступа и «Купить доступ»

Порядок запуска: заставка → ключ доступа → выбор должности (один раз, меняется в настройках) → приложение.

Ключ один для всех и действует, пока вы его не смените:

```
npm run access -- новыйключ
```

Затем опубликуйте обновление — у всех попросит новый ключ. В коде хранится только «отпечаток» ключа.

Кнопка **«Купить доступ»** открывает чат с вами в Telegram с готовым текстом и ID человека. Впишите свой username в `src/config.ts`:

```ts
export const ADMIN_TELEGRAM_USERNAME = 'ваш_username';
```

> Это защита от случайных людей, а не от взломщика: без сервера надёжнее не сделать.

## Добавление пациента

- Обязательно: ФИО, полис, **график** и **дата первого визита** — оба выбираются явно, ничего не подставляется само. Ниже сразу видны даты следующих визитов.
- Полис вводится только цифрами, пробелы ставятся сами: `7700 1234 5678 9012` (16 цифр).
- Телефоны — `+7 909 909-97-97`; первую 8 можно не стирать. Неполный номер не сохранится.
- Если такой полис уже есть — приложение предупредит и предложит открыть существующего.

## Справка: как добавить статью или новость

Откройте файл **`src/content/articles.ts`**. Вверху файла — инструкция и правила разметки. Коротко:

1. Скопируйте любой блок `{ id: ..., title: ..., body: \`...\` }`.
2. Поменяйте `id`, раздел (`news`, `work`, `dressings`, `contacts`), дату и текст.
3. Опубликуйте обновление.

В тексте: `## Заголовок`, `- пункт`, `> важное`, `| Имя | Должность | +7 900 000-00-00` (телефон станет кнопкой звонка), `[заполнить]` — подсветится. Уберите `draft: true`, когда статья согласована.

## Обмен пациентами с коллегами

- **Один пациент**: карточка → «Поделиться» → копия в буфере → отправьте коллеге в Telegram.
- **Все**: Настройки → «Поделиться всеми пациентами».
- **Принять**: Настройки → «Обмен с коллегами» → вставить текст → «Добавить к моим». Приложение покажет, сколько новых и сколько совпало.
- Одинаковые пациенты определяются **по полису** (если полиса нет — по ФИО) и склеиваются в одного: пустые поля дополняются, телефоны, аллергии и раны объединяются, визиты — без повторов, следующий визит — более ранний.

Копия содержит данные пациентов — пересылайте только в личной переписке.

## Где хранятся данные

В облаке Telegram, отдельно у каждого сотрудника (его видит только он), и копией на телефоне. Новый телефон с тем же аккаунтом Telegram — данные на месте. Раз в неделю делайте копию: **Настройки → «Сохранить копию в Избранное»**.

## Публикация в Telegram

1. Загрузите папку в репозиторий GitHub → **Settings → Pages → Source: GitHub Actions**. Сайт соберётся сам.
2. **@BotFather** → `/newbot` → имя и username бота.
3. `/mybots` → бот → **Bot Settings → Menu Button** → адрес сайта `https://<логин>.github.io/<репозиторий>/`.
4. Откройте бота → кнопка меню.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | запуск для проверки |
| `npm test` | тесты: даты, график, хранилище, обмен, пароль |
| `npm run typecheck` | проверка TypeScript |
| `npm run build` | сборка в `dist` |
| `npm run access -- ключ` | сменить ключ доступа |

Личные ключи на каждого человека (`npm run keys:init`, `npm run key`) остались в проекте на будущее, сейчас вход по общему ключу.

## Что нового в 0.6

- **Сегодня** — проще: кольцо «отмечено из скольких», крупная карточка «Следующий» с кнопками «Был» и «Поехали», вкладки Сегодня / Завтра / Потом. Отмеченные свёрнуты в «Отмечено · N».
- **Маршрут на машине** по всем, кого ещё не посетили: «Маршрут по всем» под списком → Яндекс Карты (или Навигатор через Карты).
- **Адрес по правилам**: в поле «Адрес» — только город, улица, дом. Квартира, подъезд, этаж и домофон — отдельными полями. Приложение подсказывает, если адрес записан не так, и умеет перенести квартиру из адреса одной кнопкой. Старые данные разносятся по полям автоматически.
- **Госпитализирован** — в карточке пациента. Визиты на паузе: пациента нет в плане и он не краснеет как просроченный. Когда выпишут — «Выписан» и дата первого визита.

## Что нового в 0.7

- Строки пациентов проще: **Фамилия И. О.**, ниже полис, справа галочка. Время визита убрано — если важно, когда приходить, пишите это в комментарии.
- **Нажатие на строку** (на «Сегодня», в «Пациентах» и в календаре) выдвигает краткую информацию: полное ФИО, адрес с подъездом и этажом, маршрут, телефоны со звонком, следующий визит, комментарий и кнопку «Открыть карточку».
- **Обновления**: при открытии приложение сверяет свою версию с `version.json` на сайте. Если на сайте новее — сверху появится «Вышла новая версия · Обновить». Данные пациентов при этом не трогаются.

### Как выпустить обновление

1. Поменяйте версию в `src/config.ts` (`APP_VERSION`) — например, `0.7.0` → `0.7.1`.
2. Загрузите изменённые файлы на GitHub — Actions сам соберёт сайт.
3. У всех, кто откроет приложение, появится кнопка «Обновить».
